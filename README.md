# 👑 King Zarry AI - Multi-Platform Bot Engine

An intelligent, multi-provider AI engine and trading assistant built for Telegram and Discord. Powered by **Groq**, **Google Gemini**, and **OpenRouter**, with automated provider fallbacks, real-time market technical analysis, chart vision analysis, and voice capabilities.

---

## 📌 Overview

King Zarry AI is a multi-platform assistant that combines conversational AI, market analysis, news monitoring, chart analysis, persistent memory, and voice features.

- **Multi-Provider AI Routing:** Dynamic automatic failover across Groq, Gemini, and OpenRouter.
- **Automated Technical Analysis:** Calculates RSIs, EMAs, and risk-to-reward metrics using Twelve Data.
