# 👑 King Zarry AI - Multi-Platform Bot Engine

An intelligent, multi-provider AI engine and trading assistant built for Telegram and Discord. Powered by **Groq**, **Google Gemini**, and **OpenAI**, with automated provider fallbacks, real-time market technical analysis, chart vision analysis, and voice capabilities.

---

## 📌 Overview

King Zarry AI acts as a community assistant and technical market analyst. The underlying architecture uses input features like historical price candles, technical indicators (RSI, EMA9, EMA21, EMA50), and time-series data to evaluate market setups for Bitcoin, Ethereum, Solana, Gold (XAU/USD), and Forex pairs.

---

## ✨ Key Features

- **Multi-Provider AI Routing:** Dynamic automatic failover across Groq, Gemini, and OpenAI.
- **Automated Technical Analysis:** Calculates RSIs, EMAs, and risk-to-reward metrics using Twelve Data.
- **Chart Vision Analysis:** Analyze technical chart screenshots directly via multimodal vision AI models.
- **Discord Voice Engine:** Text-to-speech integration via `edge-tts` and `FFmpeg`.
- **Telegram & Discord Support:** Unified assistant functionality across both platforms.
